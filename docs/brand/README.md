# Pulsewatch logo

A watch face with a square digital signal on it. The signal stays up (blue), drops once for an outage (amber), and comes back up. That is what Pulsewatch watches for.

| File | Use |
| --- | --- |
| `pulsewatch-logo.svg` | Mark and name, for light backgrounds |
| `pulsewatch-logo-dark.svg` | Mark and name, for dark backgrounds |
| `pulsewatch-mark.svg` | Mark only, light backgrounds |
| `pulsewatch-mark-dark.svg` | Mark only, dark backgrounds |
| `favicon.svg` | Small sizes (browser tab, avatar). Dark tile, thicker lines |

## Colours

| | Light | Dark |
| --- | --- | --- |
| Signal up | `#2563EB` | `#60A5FA` |
| Outage | `#D97706` | `#FBBF24` |
| Outline and text | `#111827` | `#E5E7EB` |
| Background | `#FFFFFF` | `#0B1220` |

## Font

The name is set in Space Grotesk SemiBold (SIL Open Font License) and converted to vector shapes, so the SVGs look the same without the font installed.
